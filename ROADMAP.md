# Roadmap

## v0.1

- sudo, SUID/SGID and capabilities scanning;
- GTFOBins-compatible matching;
- terminal, JSON and SARIF output;
- baseline and ignore support;
- deterministic demo mode;
- signed release artifacts.

## v0.2

- GitHub Action wrapper;
- larger generated GTFOBins database;
- package manager publishing;
- Docker image scan mode;
- richer distro defaults.

## Later

- optional macOS mode;
- additional data sources beyond GTFOBins;
- HTML report export;
- policy-as-code integration.
